# Die Methode

Trainings-App für das Sechs-Bausteine-Programm mit dem eigenen Körpergewicht
(verteilte Sätze, kein Muskelversagen, Leitern, Dichte, Wellen, Schockmethode).

Eine einzige HTML-Datei, läuft im Browser und als Home-Bildschirm-App auf dem iPhone.
Alle Daten bleiben im Speicher des jeweiligen Geräts (localStorage, Schlüssel `methode.v1`).
Sicherung und Übertragung aufs andere Handy über „Einstellungen → Sicherung speichern / laden“.
